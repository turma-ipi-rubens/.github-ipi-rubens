# Plano de Testes Unitários - Skillex

O projeto já conta com uma suíte de testes muito robusta no backend e frontend usando **Vitest** e testes E2E usando **Playwright**.

## Comandos para Execução Acadêmica
* Rodar testes unitários do Backend: `cd backend && npm run test`
* Rodar testes unitários do Frontend: `cd frontend && npm run test`
* Rodar testes de integração/E2E: `npx playwright test`
